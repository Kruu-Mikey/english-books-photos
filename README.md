# english-books-photos

Public image host for the C&M Koh Phangan A1 and A2 English books in Google
Docs: Google Docs fetches each photo from here by URL. Photos only.

The record of every photo (licence, photographer, crop, size) lives in the
private textbook repo's `assets/manifest.json`, not here. Each file is named
by its image id and is exactly the file that repo commits.
